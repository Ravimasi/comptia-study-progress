# Study Progress Monitor — CompTIA A+ Core 1 (220-1201)

A single-page study tracker built for one purpose: preparing for the CompTIA A+ Core 1 (220-1201) certification exam. Educational use only.

## What it does

**Overview** — dashboard showing overall checklist completion and practice quiz accuracy, broken down by domain (weighted to match the real exam: Mobile Devices 13%, Networking 23%, Hardware 25%, Virtualization \& Cloud 11%, Troubleshooting 28%).

**Checklist** — all 5 domains and their objectives from the 220-1201 exam blueprint. Click to check off what you've studied; progress is saved locally.

**Practice Questions** — two modes:

* *Multiple Choice*: a 90-question original question bank ("Core Bank"), or your own questions ("My Questions") — kept as a separate set. Filter by domain, get instant feedback and explanations.
* *Flashcards*: flip-card review with spaced repetition (Again/Hard/Good/Easy ratings schedule each card's next review, like Anki). Paste in your own Q\&A pairs to add to the deck.

**Mock Exam** — a timed 90-minute, up-to-90-question simulation matching the real exam's domain weighting. By default it draws from the original question bank; optionally build it entirely from your own Custom Questions and/or Flashcards instead.

Other: dark mode toggle, all progress/questions/schedule saved to your browser's local storage (no account, no server).

## Running it

Open `index.html` directly in a browser, or host it as a static site (e.g. GitHub Pages) for access from any device — your saved progress is per-browser either way.
